# Компас Ниши + Пульс-дуэль

Интерактивный опросник ниши и playable-прототип игры для смартфона.

> Перенос на свой ПК: см. **[HANDOFF.md](./HANDOFF.md)**

## Что внутри

- Опросник «Компас Ниши» (12 вопросов → рейтинг направлений)
- Выбор игровой механики под ~3 ч/день
- Прототип **Пульс-дуэль**: timing-кольцо + асинхронный вызов другу по ссылке

## Требования

- Node.js **22+** (см. `.nvmrc`)

## Запуск

```bash
npm install
npm run dev
```

- Компас: [http://127.0.0.1:4721](http://127.0.0.1:4721)
- Игра: [http://127.0.0.1:4721/?play=1](http://127.0.0.1:4721/?play=1)

## Как играет дуэль

1. Сыграй раунд (тап / Space, когда стрелка в золотой зоне)
2. Нажми «Вызвать друга» — уйдёт ссылка со счётом
3. Друг открывает ссылку, видит твой счёт и пытается побить

## Скрипты

- `npm run dev` — локальный сервер на порту `4721`
- `npm run build` — production-сборка
- `npm run preview` — превью сборки
- `npm run lint` — lint
