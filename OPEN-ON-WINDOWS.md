# Как открыть на Windows (если bat «ничего не дал»)

## Важно

Ссылка `http://127.0.0.1:4721` **не откроется сама по себе**.  
Она работает только пока в терминале крутится `npm run dev`.

## Шаг за шагом

### 1) Скачай свежий ZIP

https://github.com/ssspp068-maker/pulse-duel-download/archive/refs/heads/main.zip

Если браузер ничего не качает — открой страницу репозитория и жми зелёную кнопку **Code → Download ZIP**:  
https://github.com/ssspp068-maker/pulse-duel-download

### 2) Распакуй

Правый клик по ZIP → **Извлечь всё…**  
Должна появиться папка вроде `pulse-duel-download-main` с файлами:
- `package.json`
- `setup-windows.bat`
- папка `src`

### 3) Запусти установку правильно

Не из архива — только из **распакованной** папки.

**Вариант A (лучше):**
1. В папке зажми `Shift` + правый клик по пустому месту  
2. «Открыть окно PowerShell здесь» / «Открыть в терминале»  
3. Вставь и Enter:

```powershell
.\setup-windows.bat
```

**Вариант B:**
Правый клик по `setup-windows.bat` → **Открыть**  
Окно **не должно мгновенно исчезнуть**. Если исчезло — используй вариант A.

### 4) Если пишет, что нет Node.js

1. Поставь: https://nodejs.org/ (LTS, галка **Add to PATH**)  
2. **Полностью закрой** все окна терминала  
3. Снова запусти `setup-windows.bat`

Проверка:

```powershell
node -v
npm -v
```

### 5) Когда всё ок

В окне будет что-то вроде `Local: http://127.0.0.1:4721/` — тогда открой:

- Игра: http://127.0.0.1:4721/
- Компас: http://127.0.0.1:4721/compass

Окно терминала **не закрывай**, пока играешь.

## Если снова «ничего»

Пришли скрин **всего** окна терминала после запуска  
`.\setup-windows.bat` из PowerShell — по тексту ошибки сразу починим.
